### HOW TO SET UP AND RUN

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # On Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data
python manage.py runserver 8000
```

### 2. Frontend Setup (React + Vite)

```bash
cd frontend
npm install
npm run dev
```
